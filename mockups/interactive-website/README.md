# KhataPOS interactive UI mockup

Open `index.html` in a browser to explore the standalone design preview. Use the role selector to switch between owner/admin, cashier/staff and inventory manager navigation, and Android view to inspect the narrower layout. Web and desktop share the wide layout.

This is an illustrative prototype with sample data, not a production client. Buttons and tabs show intended interaction points; they do not create records, process payments, enforce permissions, or implement offline sync. The role visibility is illustrative and must be reconciled with server-side authorization when the clients are built. The existing backend is untouched. Android is the only mobile platform included in this concept.

The reference Behance page could not be fetched directly; the visual direction uses the accessible reference listing's blue, dark navy and light neutral palette. Screen coverage is based on the current requirements and wireframes; detailed subflows and edge states will need further design before implementation.
