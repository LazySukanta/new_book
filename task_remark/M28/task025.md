# Task 025 - M28 shared website shell

The paired workspace has an overview and a read-only stock page. It uses a 246 px sidebar on desktop, a keyboard-operable navigation dialog on narrow screens, and an active branch switcher that remembers the authorized branch in the session. Every Livewire update rechecks the staff account, tenant, device and branch. Stock values are visible only with report permission.

The shell keeps the reference's navy and blue palette, branch selector placement and light table surfaces. The overview uses recorded sales and stock data. On narrow screens, SKU appears below the product name so quantities and values stay visible. Blade components provide the shared layout, navigation, dialog, field, table and feedback. Livewire supplies its own Alpine runtime.

Only the implemented workspace pages appear in navigation. The mockup POS captures remain a reference for M32. Login and administration screens are next in M29.
